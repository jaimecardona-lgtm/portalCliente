Flujo de autorización (nivel B)

  1. El navegador envía el token de Supabase. FastAPI lo verifica (firma, emisor, audiencia y caducidad).
  2. FastAPI lee las membresías de tenant activas y elige la empresa (X-Tenant-Id solo entre las suyas).
  3. Con SET LOCAL ROLE portal_app y el usuario fijado, RLS limita las operaciones al cliente final asignado.
  4. Una operación sin cliente asignado no aparece en ninguna respuesta del portal.
  5. Logix, cuando exista, usará los mismos filtros: el modelo no puede saltarlos.
